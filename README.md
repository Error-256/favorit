# Поиск автозапчастей и аналогов

## Запуск

```bash
npm install
cp .env.example .env
npm run dev
```

## Как работает

1. **Шаг 1.** Ввод артикула → через 600 мс после паузы (от 3 символов) или по Enter уходит
   `GET ?key=…&number=…`. Из массива `goods` собирается уникальный список брендов.
2. **Шаг 2.** Клик по бренду → `GET ?key=…&number=…&brand=…&analogues=on`.
   В таблицу выводится сама деталь и её `analogues`: производитель, название,
   **цена** и **остаток** (по каждому складу из `warehouses`).

## Обработка ошибок и состояний

| Ситуация                                                           | Что видит пользователь                            |
| ------------------------------------------------------------------ | ------------------------------------------------- |
| Идёт запрос                                                        | спиннер (`Loader`)                                |
| `{"error": "..."}` от API (Empty key!, Invalid key client! и т.д.) | красный alert с текстом ошибки + «Повторить»      |
| Сбой сети / HTTP-ошибка / не JSON                                  | красный alert + «Повторить»                       |
| Не найдено (массив с одной пустой структурой, `goodsID` из нулей)  | «ничего не найдено»                               |
| Быстрый ввод — старые ответы приходят позже новых                  | учитывается только последний запрос (`requestId`) |
